# AI Video Director Toolkit

Most people try to create AI videos by writing prompts.

## The Director Approach

Instead of:

Prompt → Video

Think like this:

Idea  
↓  
Hook  
↓  
Scenes  
↓  
Emotion  
↓  
Ending  

This simple shift makes AI videos much more coherent.
